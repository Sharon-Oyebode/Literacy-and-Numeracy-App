# Literacy-and-Numeracy-App
This file will explain how to compile and run the program.  It will also explain how the program works.

It is suggested you follow all the steps listed below.  In the section "Running the program" below, I will include instructions on how to run a version without needing to do anything else.
By following the steps and compiling the program before running it, you will ensure you have the most recent version of the program.

PLACING THE FILES ON YOUR COMPUTER:
In order for this program to work correctly you will need to make sure you have all of the following files saved in the same folder location on your computer.
1. Capstone.java
2. alphabets.txt
3. basicWords.txt
4. simpleSentences.txt
5. numbers.txt
6. basicOperations.txt
7. quizQuestions.txt
8. instructionsHelp.txt

COMPILING THE PROGRAM:
Go to the folder where you saved all of the files above.  Make sure nothing in the folder is selected.  Hold the shift button down and, at the same time, right click on a blank section of the folder.
This should open a menu.  From the menu select "Open PowerShell window here".  When the power shell opens you will type "javac CapstoneLiteracyNumeracyApp.java" and press enter.  This will compile the program.

javac 
CapstoneLiteracyNumeracyApp.java
Main-Class:
CapstoneLiteracyNumeracyApp
jar cfm LiteracyNumeracyApp.jar
manifest.txt *.class
java - jar LiteracyNumeracyApp.jar

RUNNING THE PROGRAM:
In the PowerShell window (see above step if you are not sure what this is) you will type "java Capstone".  This will run the program.

If you wanted to run this without having to compile it first, make sure you have all 10 files listed above plus the file "CapstoneLiteracyNumeracyApp.class".  Then you can open the PowerShell window and run the program as shown above.

INSTRUCTIONS:
Navigate the Main Menu:
Enter the number for the menu option of your choice 
Press 1 for Literacy Lessons
Press 2 for Numeracy Lessons 
Press 3 for Quizzes
Press 4 to view Progress
Press 5 to Exit

Follow the lesson prompts:
In Literacy lessons
learn the alphabets, simple words and simple sentences. Follow the on screen instructions.

IN NUMERACY LESSONS
 learn numbers, basic math operations like addition, subtraction, multiplication and division

Take Quizzes
Answer questions by typing the correct option number. Your score would be displayed afterwards.

View Progress
Check the completed lessons and your quiz scores.

Exit the Program
select option 5 to close the app.
